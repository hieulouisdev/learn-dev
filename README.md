## Welcome, Future Developer!

If you have never written a single line of code in your life, you are in exactly the right place. This repository was built for you. Most programming tutorials assume you already know "a little bit" of something. We do not. We start from the very beginning, from the moment you do not even know what a "tag" is, what a "selector" is, or why a computer even understands anything you type.

Every lesson here is written in plain English. Every concept is explained with everyday analogies. Every example is small enough to read in 30 seconds, but rich enough to actually teach you something real. By the time you finish this curriculum, you will not just be able to "copy code from the internet" — you will understand why that code works, how to change it, and how to write your own from scratch.

### What You Will Learn

This curriculum is organized into modules. Each module focuses on one language or one major topic. Inside each module, lessons are numbered from `01` upward, and each lesson is a standalone Markdown file you can read in order. Every lesson includes:

- A clear, friendly introduction explaining what the lesson is about and why it matters.
- A list of learning objectives so you know exactly what you will be able to do after finishing.
- Multiple code examples with line-by-line explanations of what each line does.
- "Try it yourself" exercises so you can practice immediately.
- A "Common Mistakes" section showing the errors beginners make most often, so you can avoid them.
- A short summary you can use as a quick reference later.

You should read the lessons in order the first time, because later lessons build on earlier ones. After you finish a module, you can come back to any lesson as a reference whenever you forget something — that is completely normal and expected.

### How to Use This Repository

You do not need to install anything to read the lessons. You can read everything here directly on GitHub. However, to actually write code and practice, you will eventually need a code editor. We recommend [Visual Studio Code](https://code.visualstudio.com/), which is free and works on Windows, Mac, and Linux. We will explain how to install it step by step in the first lesson.

A typical study session looks like this:

1. Open the lesson file on GitHub and read it from top to bottom.
2. Open your code editor side by side.
3. Type out every example yourself. Do not copy and paste. Typing builds muscle memory.
4. Do every "Try it yourself" exercise before moving to the next lesson.
5. If you get stuck, re-read the "Common Mistakes" section — your answer is probably there.
6. Once you feel confident, move to the next lesson.

### A Note on Pace

Learning to program is not a race. Some lessons will feel easy and you will finish them in 15 minutes. Others will feel confusing and you may need to read them three times before things "click." That is completely normal. Every developer, including the ones who look like geniuses on Twitter, went through the same confusion. The only difference between people who succeed and people who quit is that the people who succeed kept going even when they felt stupid.

If a concept does not make sense, do not skip it. Read it again. Try the example again. Take a 10-minute break and come back. You will get it. We promise.
