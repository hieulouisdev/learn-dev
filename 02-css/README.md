Welcome to Module 02! You finished HTML, and you can now build the **skeleton** of any web page. But your pages look... ugly. They have default browser styling — black text on a white background, no spacing, no colors, no layout. CSS is what turns that skeleton into a beautiful, modern, professional-looking website.

CSS stands for **Cascading Style Sheets**. By the end of this module, you will be able to style any web page you can imagine — colors, fonts, layouts, animations, responsive design. Let's begin.

---

## What is CSS?

CSS is a **style sheet language** that describes how HTML elements should look. While HTML describes structure ("this is a heading, this is a paragraph"), CSS describes appearance ("this heading is blue, this paragraph has 20 pixels of padding").

The three letters of CSS tell you three important ideas:

- **Cascading** — when multiple rules apply to an element, the browser uses a "cascade" — a priority order — to decide which rule wins.
- **Style** — CSS is about appearance, not structure or behavior.
- **Sheets** — you write CSS in a separate file (a "sheet") linked to your HTML. You can also write it inline, but separate files are the professional approach.

You will write CSS for the rest of your web development career. Mastering it takes years, but the fundamentals are simple — and this module gives you all of them.

## How to Practice

For this module, you will need:

1. The HTML files you created in Module 01.
2. A new file called `style.css` (or similar) in the same folder.
3. A code editor (VS Code is recommended).
4. A web browser.

For every lesson, you should:

1. Read the lesson from start to finish.
2. Open an existing HTML file (or create a new one).
3. Create or open a `style.css` file.
4. Add the CSS the lesson describes.
5. Save and refresh the browser to see the changes.

You should also experiment — change numbers, try different values, see what happens. CSS is forgiving; you can't break anything by trying.

## Estimated Time

If you spend 30–60 minutes per lesson (including practice), this module should take **12 to 20 hours of total study**. Take your time. Don't try to finish in one weekend.

The most important lesson in this module is **the box model** (Lesson 06). If you understand the box model, you understand 80% of CSS. Make sure you really, really get it before moving on.
