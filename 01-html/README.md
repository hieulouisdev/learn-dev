## What is HTML?

HTML stands for **HyperText Markup Language**. Let's translate that scary name into something friendly:

- **HyperText** just means "text that links to other text." When you click a link on a website and it takes you somewhere else, that is hypertext.
- **Markup** means "annotations around text." You write little notes around your text that tell the browser what each piece of text is — is it a heading? a paragraph? a list item?
- **Language** means it has rules. You have to follow the rules for the browser to understand you.

So HTML is **a way to write text with little annotations that tell the browser what each piece of text is, and that allows linking pages together.**

The most important thing to remember is this: **HTML is not a programming language.** It cannot calculate, it cannot make decisions, it cannot run loops. It only describes the structure of content. Think of HTML as the skeleton of a body, CSS as the skin and clothes, and JavaScript as the muscles that move everything. We will focus on the skeleton first.

## How to Practice

For this entire module, all you need is:

1. A code editor. We recommend [Visual Studio Code](https://code.visualstudio.com/). It is free.
2. A web browser. You already have one — Chrome, Firefox, Edge, or Safari all work.
3. Your computer's file system. You will create a folder on your computer, save HTML files inside, and double-click them to open them in the browser.

That's it. No servers, no installations, no internet required to test. You write HTML, save the file, refresh the browser, and see your changes instantly. This fast feedback loop is one of the most satisfying parts of learning web development.

## Estimated Time

If you spend about 30 to 60 minutes per lesson, including typing out the examples and doing the exercises, you should complete this module in roughly **10 to 15 hours of total study**. Take breaks. Do not try to do all 13 lessons in one day. Your brain needs sleep to absorb new concepts.
